## Provenance

The storage engine is original work. Its `db` facade, several serializers and a
number of regression scenarios were ported from earlier MapDB releases
(MapDB 1, 2 and 3, https://github.com/jankotek/mapdb) by the same author. The
Rust and Zig implementations are ports of the Java reference implementation in
this project; the Go port is specification-only.

This project does **not** derive from Eclipse Collections. The sibling
`mapdb-java` collections library does, and carries its own notice to that
effect; nothing in this repository does.
